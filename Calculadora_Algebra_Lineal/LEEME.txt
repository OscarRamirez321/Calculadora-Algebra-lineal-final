CALCULADORA DE ÁLGEBRA LINEAL (MTM0120)

Cómo ejecutarla
  1. Abra esta carpeta en Visual Studio Code.
  2. Ejecute main.py (botón Run o: python main.py).
  3. Se abre una pestaña del navegador con la calculadora. Todos los cálculos los hace Python.
  4. Para cerrar, vuelva a la terminal y presione Ctrl+C.

Versión de texto (sin navegador):  python main.py --consola

Requisitos: Python 3.8 o superior. No necesita instalar ninguna librería.
